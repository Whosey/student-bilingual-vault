# 学生课程知识库第一版设计

学生把英文课内资料放进收件箱，运行一次 Codex 整理流程。整理完成后，从 Obsidian 的课程页点开资料，就能按原文顺序逐段读英文和中文，并跳回对应的 PDF 页面。先用一门示例课验证全流程。

## 两种做法

简短中文导读方便浏览很多资料，读到正文仍需按需解释。全文逐段中英对照的生成和校对成本更高，可以从头读到尾并随时核对原文。用户选择逐段中英对照作为默认，导读属于以后可以追加的功能。

## 使用流程

1. 把英文 PDF 放入收件箱；可告诉 Codex 课程名，或者请它根据可见内容判断。课程不明确时可先生成待归类的双语笔记。
2. 学生主动调用一次 Codex 整理工作流。按 PDF 文件页码提取内容，保留原文件。输出一份 Markdown 阅读笔记，按页分节，每个原文段落下紧跟中文译文。标题、列表、公式和专业术语保留可核对的对应关系；图表引用所在 PDF 页，可识别的图注可以翻译。
3. 打开 Obsidian 的「课程页 → 资料标题（中英对照）」。资料标题指向阅读笔记，阅读笔记顶部链接原 PDF，每节标题附近提供跳到原始 PDF 页的链接。无需改动 PDF 内容。
4. 学生可以在阅读笔记底部的「我的疑问」记录自己的理解，或链接到单独的复习笔记。

## 第一版范围和处理规则

- 首先支持带可提取文字的 PDF。扫描图片、复杂排版中无法可靠提取的页面，以及暂未支持的附件格式，应显示能操作的提示。扫描件需先提供文字层或转写；PPT 可先导出为带文字的 PDF。图片、扫描手写、复杂表格的专门识别可后续扩展。
- 翻译在 Codex 被主动调用后生成并缓存成文件，查看笔记使用 Obsidian 本地 Markdown 和核心功能。Codex 整理工作流由 AGENTS.md 和一份中文说明定义。提取器的具体选择、目录与字段名交给实现者，以跨平台、无模型密钥、少安装步骤为原则；如果需要额外装提取依赖，应在快速开始里明确。无额外模型 API 密钥指模板不要求用户单独配置密钥，Codex 使用自己的正常登录。
- 可读的页写入笔记。过长文件分段处理，进度标明已完成页及待处理页。失败或提取顺序不能确认时明确标记页码和原因，仍保留原文入口。再次运行同一份原件时沿用原笔记，只填待处理段；已经确认的内容、学生疑问和人工译文修改要保留。全页处理完成才显示完成。不同文件碰巧同名时不覆盖；无法确认课程时进入待归类入口。
- 公开仓库包含模板、中文快速开始、Codex 整理规则、开源许可和虚构演示资料。真实课件、个人笔记与真实译文用于用户自己的学习库。课程页入口、示例工作流有说明，中文界面和原英文标题都可搜索。
- 第一次验收时把虚构的多页 PDF 放进收件箱，整理后从课程页进双语阅读笔记并跳回 PDF 指定页；用一处不可可靠读取的页验证状态及反馈；补写一条个人疑问重新运行，核对原件字节、阅读笔记数量、课程索引、人工编辑以及未处理页没有丢失。
